# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Delegated: plain static HTML, CSS, and JavaScript, selected for a fast and dependable GitHub Pages deployment with no runtime dependencies.

## Users

People looking for small, freely available browser tools for practical Singapore and event-planning tasks.

## Product Purpose

Provide one clear public directory for the owner's small web tools, so visitors can understand each tool at a glance and open the appropriate deployed app.

## Positioning

This is a deliberately small, direct collection: each project is a usable public tool, not a sign-up funnel or account-based product.

## Operating Context

Visitors arrive from a shared link, the owner's GitHub profile, or another tool. They scan the collection, choose a tool, and leave the gallery to use its deployed GitHub Pages app.

## Capabilities and Constraints

- Displays three live GitHub Pages projects as linked project cards.
- Contains no accounts, forms, analytics, persistence, or user-input collection.
- Must remain deployable as a GitHub Pages static site.
- Future projects in the `mini_projects` parent folder should use the parent-scoped Impeccable skill for styling work.

## Brand Commitments

- The gallery's visual identity is locked to bold flat-vector illustration: thick, rounded geometric line art on saturated colour fields, paired with pale information surfaces.
- New project cards must extend this vocabulary rather than introducing generic icon-library glyphs, stock imagery, gradients, glass effects, or a competing illustration style.

## Evidence on Hand

- SUTD Commute Cost: `https://cyrahahaha.github.io/sutd-commute-cost/`
- Sticker Studio: `https://cyrahahaha.github.io/sticker-studio/`
- BTO Budget Calculator: `https://cyrahahaha.github.io/BTO-Budget-Calculator/`
- The existing repository READMEs provide the project descriptions.

## Product Principles

- Let visitors reach a useful tool in one clear action.
- Make the absence of accounts and retained inputs easy to understand.
- Keep the directory lightweight, legible, and durable.
- Give each tool a distinct visual identity while keeping the collection coherent.

## Accessibility & Inclusion

Use semantic navigation and headings, visible keyboard focus, sufficient contrast, reduced-motion support, and layouts that remain readable from small phones to wide desktops.
